# Krunal Suthar Portfolio — Design Rules

## Color System (STRICT — never deviate)

| Token | Value | Usage |
|---|---|---|
| Main background | #0A0A0A | Page background, hero |
| Section background | #111111 | Alternate sections |
| Card background | #181818 | All cards, modals, forms |
| Primary text | #F5F5F0 | Headings, important text |
| Secondary text | #A3A3A3 | Body text, descriptions |
| Border | #292929 | All borders, dividers |
| Accent | #C6A15B | Primary accent, labels, icons, CTAs |
| Accent hover | #D8B875 | Hover states on accent elements |

## Rules
- NEVER use violet, purple, pink, blue or any other accent color
- NEVER use white/10, white/[0.06] for borders — use #292929
- ALL gradients use #C6A15B → #D8B875 only
- ALL glow/blur backgrounds use #C6A15B with low opacity
- Scrollbar thumb: #C6A15B → #D8B875
- Focus ring: #C6A15B
- Orange (#E85D26) is REMOVED — replace with #C6A15B everywhere
- Gold (#C9A84C) is REPLACED by #C6A15B everywhere

## Typography
- Headings: Space Grotesk (var(--font-space))
- Body: DM Sans (var(--font-dm))

## Component Rules
- Card bg: #181818
- Card border: #292929
- Input bg: #181818
- Input border: #292929
- Input focus border: #C6A15B
